# Digital Twin Universe 

The Amplifier Digital Twin Universe as an Smart Tool. It can be used in any coding agent with by installing our skill:

```
npx skills add DavidKoleczek/amplifier-smart-tool-digital-twin-universe
```

Alternatively it can be used as a Python library:

```
uv add "amplifier-digital-twin-universe @ git+https://github.com/DavidKoleczek/amplifier-smart-tool-digital-twin-universe"
```

Or as a CLI tool
```
uv tool install git+https://github.com/DavidKoleczek/amplifier-smart-tool-digital-twin-universe
```

## Key Features

- Install: Intelligently walks a user through setting up the Digital Twin Universe for the first time on supported systems
- Doctor: Troubleshoots Issues
- Create Profile: Intelligently walks you through building a Digital Twin Universe Profile that is ready to launch
- Manager: Intelligent wrapper around the remaining deterministic capability
- Deterministic "wrapper" around the existing API: launch, exec, destroy, etc
